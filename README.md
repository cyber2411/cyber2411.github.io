# Syed Areeb Ali — Portfolio

A responsive, animated static portfolio for Notion workspaces, Excel and Google Sheets business systems, and digital products.

## Local use

Open `dist/index.html` in a modern browser. The page has no build step or account requirement. Its font uses a web request when available and falls back to system fonts offline.

## Free hosting

The included GitHub Actions workflow publishes the contents of `dist/` to GitHub Pages after every push to the `main` branch. In the GitHub repository, set **Settings → Pages → Source** to **GitHub Actions** once. No paid hosting or build service is required.
